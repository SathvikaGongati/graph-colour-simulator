Graph Colouring Simulator Using Python
About the Project

Chromatic Studio is an interactive graph colouring simulator developed using Python and Tkinter. It allows users to create graph nodes, connect them with edges, and colour the graph while ensuring that adjacent nodes do not have the same colour.

Objectives
To understand the Graph Colouring Problem.
To implement the Backtracking Algorithm.
To provide an interactive interface for creating and colouring graphs.
To identify conflicts between adjacent nodes.
Technologies Used
Python
Tkinter
Graph Theory
Backtracking Algorithm
Features
Interactive graph creation
Add and connect nodes
RGB colour selection
Automatic graph colouring
Step-by-step colouring
Conflict detection
Node and edge deletion
Graph statistics
Algorithm

The project uses the Backtracking Algorithm to assign colours to graph nodes. It checks whether a colour can be assigned to a node without conflicting with its adjacent nodes. If a conflict occurs, the algorithm tries another colour.

How to Run
Install Python 3 on your computer.
Download or clone this repository.
Open a terminal in the project folder.

Run the following command:
graphsimulator.py

Expected Result

The application opens a graphical interface where users can create graphs, connect nodes, select colours, and run the graph colouring algorithm.
